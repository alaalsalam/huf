# HUF Enhanced AI Chat Setup

1. Install and migrate the HUF app.
2. Configure `AI Provider` with the OpenAI key using the password field.
3. Configure `AI Model` and `Agent`.
4. Open `HUF AI Settings` and enable the Desk widget, RAG, redaction, and confirmation.
5. Visit `/app/huf-chat` or use the floating Desk button.
