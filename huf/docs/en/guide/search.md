# Search the system guide

This generic service explains the guide itself. It does not define an organisation's business policy.

## Purpose and prerequisites

Signed-in employees can find instructions for a screen, read their source and start an available tour.
The site administrator must enable the guide. You need permission to read the article; no AI model or API key is needed.

## Steps

1. Open **System Guide** on any Desk screen.
2. Choose **Guide for this screen** for configured documentation.
3. Use **Search the guide** to search for a few words such as **system guide**.
4. Select a result to read it in the panel.
5. Choose **Open source** to open the complete Compendium article.
6. On the documentation screen, open the guide and choose **Guide me step by step**.

## Result and next action

You have read an authorised source and started a tour. Read the approved service instructions before doing business work.
Results are actual documentation, not generated answers. The guide does not read form values or transactions or act on your behalf.

## Known problems and support

If no article appears, try fewer words or ask the administrator about access.
Enter an approved error code in **Explain a known error**. An unknown code is explicitly undocumented.
Use the configured support instructions if shown. Nothing is sent automatically.
